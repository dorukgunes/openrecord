# Code of Conduct

OpenRecord follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be kind, assume good intent, and focus on what's best for the people using and building this
project. Harassment, personal attacks, and publishing others' private information aren't tolerated anywhere in the
project's spaces: issues, pull requests, discussions, and anywhere else you're representing it.

## Reporting

Report unacceptable behavior to **dorukgunes94@gmail.com**. Every report gets a prompt, confidential response, and
enforcement follows the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines),
from a warning up to a permanent ban.
